# Vial Decapper Simulator

1. Vial Decapper Software 폴더에서 **Start Decapper Simulator.cmd**를 실행합니다.
2. 시뮬레이터에서 **서버 시작**을 누릅니다. 기본 주소는 `127.0.0.1`, 포트는 `18000`입니다.
3. Vial Decapper Software에서 같은 IP와 포트를 입력하고 **Connect**를 누릅니다. CR과 LF를 모두 켭니다.
4. **HOME**을 실행하고, Test 또는 Teaching 탭에서 이동과 위치 조회를 확인합니다.
5. 시뮬레이터에서 오류 코드 9종 중 하나를 고르고 **고장 발생**을 누릅니다. 제어 앱에 오류 코드, 동작 단계, 센서 입력값과 기대값 등 해당 오류의 상세 정보가 표시되고 동작 버튼이 비활성화됩니다. Longrun에서는 해당 모듈의 오류 상태에 마우스를 올리면 상세 정보가 표시됩니다. 제어 앱의 **오류 해제**나 시뮬레이터의 **고장 해제**로 복구를 확인합니다.

Longrun은 제어 앱의 개별 TCP 연결을 해제한 뒤 Longrun 목록에 `127.0.0.1`을 추가하고 포트를 `18000`으로 맞춥니다. 해당 행만 체크하여 연결하고 **횟수 시작** 또는 **무한 시작**을 누릅니다. 여러 가상 장비를 동시에 시험하려면 시뮬레이터 창을 추가로 열고 `127.0.0.2` 등 서로 다른 IP에 같은 포트를 사용합니다.

이 프로그램은 Vial Decapper의 TCP 응답과 장비 상태를 소프트웨어로 재현합니다. 고장 주입 시 펌웨어 GERD 형식으로 시험용 센서값과 해당 오류가 발생할 수 있는 단계를 응답합니다. 현재 Longrun의 CAP/DECAP 단계에 해당 오류가 발생할 수 있으면 진행 중인 동작과 완료 횟수를 함께 기록합니다. 이동 시간과 위치는 시험용 모델이고, SAVE는 시뮬레이터를 켜 둔 동안 LOAD에 사용할 값을 메모리에 저장합니다. 실장비에서의 구동과 물리 센서 검증은 별도로 진행합니다.
